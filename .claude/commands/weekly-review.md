# Weekly costing review

Run `pools`, `margins` and `attention` through `node scripts/costing.mjs`, each with the chosen `--period=CODE`. Run `reconcile` to identify unallocated cost. Draft a review with `draft-review` and report its file path.

Lead with negative contributions and unresolved allocation gaps. Name the pool owner, evidence needed and next review date. Never describe margins as final when cost remains unallocated. Never sign off, close or send as a side effect of a review.
