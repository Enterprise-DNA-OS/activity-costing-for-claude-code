# Views without a front end

The database stores the period, cost pools, customers, activity quantities and signed calculations. The agent runs the CLI. Read-only HTML gives the weekly contribution view and reconciliation, and branded documents give finance a review pack and customer cost statements.

A browser application gives shared forms, mobile entry, live collaboration, access controls and drag-and-drop model design. This base does not supply those. It is a trusted operator's review desk. Enterprise DNA can build those interfaces and connections into the version your business needs.

Keep generated files private. Run `npm run view` and `npm run docs`, then open the generated files yourself or ask the agent to inspect them. They contain no buttons that change records.
